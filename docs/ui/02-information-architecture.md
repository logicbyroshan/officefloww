# 02 — Information Architecture

## 1. The 7 Primary Business Workspaces

Rather than presenting an overwhelming list of 18 disconnected sidebar buttons, PrintFlow organizes all manufacturing and commercial capabilities into strictly **7 primary business workspaces**:

```
+-----------------------------------------------------------------------------------------+
| [AB Logo] PrintFlow                     Search (Ctrl+K)       [🎙 Voice] [🔔] [Online] [User]|
+-------------------+---------------------------------------------------------------------+
| Workspaces        |                                                                     |
|                   |  WORKSPACE CONTENT                                                  |
| 1. Dashboard      |  • Actionable summary tiles & quick shortcuts                       |
| 2. Tasks          |  • Sub-Navigation (My, All, Board, Overdue, Blocked, Approvals)     |
| 3. Staff          |  • Workforce (Employees, Labour Contractors, Workload, Quality)     |
| 4. Stock          |  • Spreadsheet Register (Inventory, Movements, Low Stock, POs)      |
| 5. Clients        |  • Customer Hub (Clients Directory, Orders, Quotations, Approvals)  |
| 6. Billing        |  • Financial Ledger (Invoices, Payments, Client Ledger, Expenses)   |
| 7. Settings       |  • 2-Column System Settings (General, BOM, Workflows, Machines, AI) |
|                   |                                                                     |
| [< Collapse]      |                                                                     |
+-------------------+---------------------------------------------------------------------+
```

---

## 2. Workspace Domain Allocations

| Primary Workspace | Absorbed Former Submodules | Primary Business Intent |
| :--- | :--- | :--- |
| **Dashboard** | Dashboard, Quick Actions, Floor Telemetry | Answer: What is happening, what needs attention, and what can I do quickly? |
| **Tasks** | Task Queue, Production Tasks, Floor Checklist, Approvals | Manage actual operational work through spreadsheet tables and Kanban lanes. |
| **Staff** | Labour, Contractors, Operators, Workload Allocator | Unified people management, contractor piece-rates, and equipment issue. |
| **Stock** | Stock & Inventory, Purchasing & POs, Suppliers, Materials | Spreadsheet register for fast scanning, reservations, and goods receipt. |
| **Clients** | Clients Directory, Orders, Quotations & Costing, Client Approvals | Full lifecycle customer relationship, commercial proposals, and active jobs. |
| **Billing** | Billing, Invoices, Client Ledger, Payments Received, Expenses | Financial control, GST compliance, tax invoicing, and receivables tracking. |
| **Settings** | Settings, Products & BOM, Machines, Automation, Audit Trail, AI | Complete configuration and hardware parameters in a 2-column layout. |
