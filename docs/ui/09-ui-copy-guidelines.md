# 09 - UI Copy, Microcopy & Voice Guidelines

## Tone & Voice Principles
OfficeFloww is used on fast-paced factory floors and management offices. The copy is:
- **Direct & Action-Oriented**: Short verbs, clear outcomes, no ambiguous metaphors.
- **Precise & Operational**: Use actual industrial terms ("BOM Components", "Sublimation Press", "Dual Verification", "Scrap Rate %").
- **Unambiguous**: Distinguish clearly between physical inventory and reserved stock holds.

## Standard Operational Terminology

| Incorrect / Vague | Correct Industrial Term | Context |
| :--- | :--- | :--- |
| "Items left" | **"Available to Promise (ATP)"** / **"Net Available"** | Warehouse stock |
| "Things to do" | **"Factory Task Execution Queue"** | Floor tasks |
| "Check image" | **"Artwork Proof Review & Version Lock"** | Proof approvals |
| "Trash" | **"Material Scrap Rate %"** | Double-entry ledger |
| "Vendor list" | **"Labour Management & Material Credit Ledger"** | Piece-rate contractors |
| "Done" | **"Tripartite Verified Order Completion"** | Order closing invariant |

## Microcopy Guidelines for Action Triggers
- Modal headers must explain the exact consequence:
  - *Example*: "Create Production Order — Instantiate a multi-product job with automatic DAG workflow generation."
- Destructive alerts must state what cannot be undone:
  - *Example*: "Flag Operational Blocker — Halts machine scheduling for this item until resolved."
- Empty states must provide actionable next steps:
  - *Example*: "No client accounts found. Click 'Onboard Client' to register a new school or corporate account."
