# 14 — Batch Operations & High-Density UX

Manufacturing plants process thousands of items daily. PrintFlow is engineered specifically for dense desktop operations:

---

## 1. Ergonomic Density Standards

- **Row Heights**: 36px–40px standard; provides ample vertical clicking target while allowing 15–20 rows to remain in view without scrolling.
- **Monospace Numerical Columns**: All quantities, prices, SKUs, and dates use fixed-pitch fonts to ensure vertical alignment of digits.
- **Sticky Headers**: Table headers remain locked at the top of the viewport when scrolling through hundreds of materials.
- **Instant Filtering**: Search inputs filter in-memory data with a 150ms debounce, giving immediate visual feedback.

---

## 2. Multi-Item Operations

- **Batch Receipts**: Single GRN modal intake allows adding thousands of units into inventory in a single interaction.
- **Bulk Task Assignment**: Production managers can assign multi-step operations to operators with a single click.
